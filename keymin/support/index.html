Support

Help with Keymin and answers to common questions.

Contact

  • Questions and support: Keymin on GitHub
  • Bug reports and feature requests: GitHub Issues
  • Privacy questions: privacy@min.tools

When reporting a problem, include your macOS version, the Keymin version from About Keymin, whether you run skhd or skhd.zig, and clear steps to reproduce. If a line of your configuration is involved, include that line, with private commands or paths removed.

Common questions

What does Keymin need?

An Apple-silicon Mac running macOS 14 or later. Keymin can edit configurations without skhd. To run your hotkeys, install and start either skhd (brew install asmvik/formulae/skhd) or the compatible skhd.zig (brew install jackielii/tap/skhd-zig). Both read the same configuration file. Keymin does not include, start, or control skhd, and it needs no Accessibility access.

The first screen says skhd was not found, or is not running

Keymin looks for the skhd program in the usual install places and in the folders on its PATH, and checks the running processes. If nothing was found, install one of the two projects above. If skhd is installed but not running, run skhd --start-service in Terminal. Then click Check Again. You can choose or create a configuration file in the meantime.

My hotkeys do not change after I save

With hot loading on, skhd reloads the file by itself when it changes. If you run skhd with --no-hotload, run skhd --reload after saving, or open After Saving in the sidebar and let Keymin run a Shortcuts shortcut after every save, with the saved file's path as its input. Run Now on the same page runs it right away.

How do I add a binding?

Press ⌘N, then ⌘R and the keys you want. Choose what the binding does: open an app, run a command, run a different command per app, or switch skhd into a mode. Press ⌘S to write the file. Keymin writes the line in skhd's own syntax, including Apple key codes such as 0x27 for keys without a name.

How do I open my existing configuration?

Choose Configuration File… (⌘O) and pick your skhdrc, usually at ~/.config/skhd/skhdrc. If that path is a symbolic link into a repository, Keymin may ask once for access to the file it points to. The link is kept, and that file is updated with its permissions intact. Keymin remembers the file between launches until you choose Keymin → Forget File Access… or pick another file.

Why is a line marked as an error?

Keymin's parser follows the rules of skhd's own tokenizer and parser, so it flags what skhd would reject, such as a key code with lowercase hex digits (0x2c instead of 0x2C) or a mode that is used but never declared. The line is kept as it is. Fix it in the form or on the Source page; Keymin does not save while an error remains in a part of the file you can edit.

My file opened with unsaved changes right away

The file has Windows line endings. skhd would pass the carriage return at the end of each line to the shell as part of the command, so Keymin saves the file with plain line feeds. Nothing else changes.

What happens after the first 30 days?

The 30-day trial includes full access. No subscription starts and there is no charge. After the trial, Keymin shows and edits only the first five bindings in the file. The others are hidden but kept in the file and are written back unchanged when you save. Modes, the blacklist, included files, and After Saving stay editable; the Source page needs Pro. Pro brings every binding back and is a yearly subscription or a one-time lifetime purchase through the Mac App Store.

Does Keymin run my commands or send anything anywhere?

No. The commands in your file are text to Keymin. It does not run them, does not monitor keystrokes outside its own window, and does not start, stop, or signal skhd. Keymin has no network entitlement, no account, no analytics, and no developer server. See the privacy policy for details.

Where is the source?

The app repository holds the public app source under the PolyForm Strict License 1.0.0 with added permissions, so you can read exactly how Keymin reads and writes your file. Bug reports and contributions are welcome there.

How do I cancel or restore Keymin Pro?

Subscriptions are managed in your App Store settings (App Store → your name → Subscriptions). To restore a purchase on another Mac, choose Keymin → Keymin Pro… and click Restore Purchases, signed in with the same Apple Account.
