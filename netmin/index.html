One app for the whole stack

Pick a tool. Enter a target. Read the answer.

Every tool has a defined target type, command, timeout, and result presentation. Choose one from the sidebar or with ⌘K, press ⌘↩, and switch between the overview and the raw output with ⌘1 and ⌘2.

Eighty-four tools in one place

Reports, local discovery, IP and routing, DNS and DNSSEC, mail, TLS, websites, ports, and practical network utilities, all from one catalog.

Overviews and raw output

Review structured tables, metrics, findings, and device lists, then switch to the captured raw output to verify the findings.

Built for active diagnostics

Watch output while a check runs, cancel safely, rerun it, copy the result, or save a plain-text report. Recent targets make repeated work quicker.

Local-network discovery

Find devices and advertised services, inspect routes and interfaces, and choose exactly which detected networks to scan.

Checks input before running

Netmin validates domains, IP addresses, CIDR ranges, URLs, MAC addresses, and optional DNS resolvers before starting a check.

Bounded execution

Fixed command templates, restricted environments, per-tool time limits, and an 8 MiB output cap keep a failed check under control.

No extra runtimes

Netmin uses macOS system tools and its bundled helpers. It does not need Homebrew, Python, Perl, or another developer runtime.

Sandboxed

The app runs in the App Sandbox. It does not execute arbitrary commands, ask for administrator access, or depend on tools installed by a package manager.

Native and localized

SwiftUI on Apple silicon. The interface follows macOS appearance, contrast, and accent settings and is available in twenty-seven languages.

Discover the local network

Discovered devices in one table.

Local Device Sweep finds attached networks first and lets you choose which ranges to scan. The results show discovered devices, response times, interfaces, and common services, along with the scanned ranges and raw output.

  • You pick the ranges

    Netmin lists the private networks your Mac is attached to and scans only the ones you tick, one range at a time.

  • Ping and ports from the row

    Every discovered device offers a ping and a common-port check right there, so the follow-up is one click.

  • Only when you start it

    You start each local check. macOS controls Local Network access, and remote diagnostics remain available if you deny it.

Private by design

Checks go directly to the systems involved.

Netmin has no advertising, analytics, account system, or developer-operated diagnostic service. A check starts only when you choose a tool and run it, and its requests go directly to the systems that check needs.

  • Straight to the systems involved

    Depending on the tool, that is the target itself, its DNS and mail servers, a resolver you select, registries, certificate-transparency logs, or a named public lookup service.

  • Named services, no surprises

    Built-in lookups can contact Cloudflare, Google Public DNS, Quad9, OpenDNS, RIPE, Team Cymru, ipify, ipinfo.io, rdap.org, hstspreload.org, and crt.sh. These services receive your public IP address and the query needed for the check, under their own privacy policies. You can avoid those tools or choose another resolver where supported.

  • Output stays in memory

    Complete diagnostic output is discarded when you replace or close the result or quit. A report is written to disk only where you choose to export it. Nothing is sent to the developer.

The details

Small things, done carefully.

Requirements

An Apple-silicon Mac running macOS 14 or later. Some checks contact the target or a named public lookup service and need network access. Local discovery also needs macOS Local Network permission.

Controlled execution

Netmin launches only fixed command templates and bundled shell helpers. Inputs are checked before they are passed to the tools. Each run has its own timeout and an 8 MiB combined-output limit, and Local Device Sweep scans selected ranges sequentially.

Documented tools

Each tool's catalog entry defines its input, command, and result view. You can inspect the catalog in the source repository.

What stays on the Mac

Preferences, favorites, up to eight recent targets, the trial start date, and today's Free request count live in the app container. Clear Recent Data removes the targets.

Export

With Pro, save a report as plain text through the standard save panel. Complete diagnostic output is not saved automatically.

Follows your Mac

Light and Dark appearance, increased contrast, reduced motion, your accent color, and VoiceOver labels on the controls.

Source available

The source is on GitHub under the PolyForm Strict License 1.0.0 with added permissions. You can inspect every command template.

Resolver of your choice

Where a tool offers a resolver field, choose a public DNS service, your own server, or your Mac's default resolver.
