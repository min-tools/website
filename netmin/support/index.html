Support

Help with Netmin and answers to common questions.

Contact

  • Questions and support: Netmin on GitHub
  • Bug reports and feature requests: GitHub Issues

When reporting a problem, include your macOS version, the Netmin version from About Netmin, the tool you used, and clear steps to reproduce. Remove private addresses, hostnames, and diagnostic output before posting.

Common questions

What does Netmin need?

An Apple-silicon Mac running macOS 14 or later. Netmin uses macOS system tools and its own bundled helpers, so it does not need Homebrew, Python, Perl, or another runtime. Some checks contact the target or a named public lookup service and need network access. Local discovery needs macOS Local Network permission.

How do I run a check?

Choose a tool from the sidebar or press ⌘K and type its name. Enter a target when the tool needs one and press ⌘Return. ⌘1 shows the overview and ⌘2 the raw output. Escape starts a new report, and ⌘⇧C copies the raw output. Pro also provides Copy Summary and report export.

What happens after the first 30 days?

Netmin starts a 30-day Pro trial after you accept its notice at first launch. No subscription starts and there is no charge. After the trial, every tool and its raw output remain available, with up to five new diagnostic requests per local calendar day. Viewing or copying an existing result does not count. Pro removes the daily limit and adds structured reports, report export, and summary copying. It is available as a yearly subscription or a one-time lifetime purchase through the Mac App Store.

Local Device Sweep finds nothing, or asks for permission

macOS asks for Local Network permission before discovery can run. If you declined it, turn it on under System Settings → Privacy & Security → Local Network. The sweep also needs a private IPv4 network on an active interface; add a range to scan if none is detected. Remote diagnostics keep working without local access.

A check timed out or was cut short

Each check has a time limit and an 8 MiB output limit. Netmin stops the process when it reaches either limit and explains why. Review Raw output to see how far it got before running it again.

Which services does a check contact?

Only the systems that check needs: the target, its DNS and mail servers, a resolver you select, registries, or a named public lookup service such as Cloudflare, Google Public DNS, Quad9, OpenDNS, RIPE, Team Cymru, ipify, ipinfo.io, rdap.org, hstspreload.org, or crt.sh. Netmin never sends targets, queries, or results to the developer. The privacy policy lists what each service receives.

Where are my results kept?

Complete output stays in memory while you view it and is discarded when you replace or close the result or quit. A report is written to disk only when you choose Save Report and pick a location. Up to eight recent targets stay in the app container until you choose Netmin → Clear Recent Data….

Where is the source?

The app repository holds the public app source under the PolyForm Strict License 1.0.0 with added permissions, so you can read every command template Netmin runs. Bug reports and contributions are welcome there.

How do I cancel or restore Netmin Pro?

Subscriptions are managed in your App Store settings (App Store → your name → Subscriptions). To restore a purchase on another Mac, open Netmin Pro from the app menu and choose Restore Purchases, signed in with the same Apple Account.
