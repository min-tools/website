Support

Help with Paletmin and answers to common questions.

Contact

  • Questions and support: Paletmin for Chrome or Paletmin for Firefox on GitHub
  • Bug reports and feature requests: GitHub Issues for Chrome or Firefox
  • Privacy questions: privacy@min.tools

When reporting a problem, include your browser and its version, the Paletmin version shown at chrome://extensions or about:addons, the address of the website, and clear steps to reproduce. Leave out private page content.

Common questions

How do I install Paletmin?

In Chrome, add it from the Chrome Web Store. In Firefox, add it from Mozilla Add-ons. Both listings are free, and the browser keeps the extension up to date.

What does Paletmin need?

Google Chrome 118 or later on macOS, Windows, Linux, or ChromeOS, or Firefox 140 or later on desktop. Other Chromium-based browsers and Firefox for Android are not tested. Paletmin needs no account and no other software.

How do I switch a tab?

Click the Paletmin icon in the toolbar. Each click moves the tab to its next mode: Auto, then the palette the browser is not using, then the other one, then back to Auto. The first click always changes the page. The icon shows the tab's current mode.

Can I use a keyboard shortcut?

Yes. In Chrome, open chrome://extensions/shortcuts and assign a shortcut to Paletmin. In Firefox, open about:addons, click the gear, and choose Manage Extension Shortcuts. The shortcut does the same as a click on the icon.

Why does the browser say Paletmin can access my data on all websites?

Paletmin runs a small script in each tab. To switch a page, the script reads the page's stylesheets and swaps the light and dark rules in them. Chrome and Firefox describe any script that runs on a page that way. The script keeps everything in the tab, and Paletmin makes no network requests. See the privacy policy.

A website did not change

Paletmin only changes which palette a website thinks you prefer. If the website has no dark theme, or does not follow that preference, nothing changes. Rules inside stylesheets loaded from another website, and styles inside shadow roots, are left as they are, so parts of some pages keep their palette. Chrome's own pages and the Chrome Web Store, and Firefox's internal pages, PDF viewer, and protected Mozilla sites, do not allow extensions to run.

Does it work on local files?

In Chrome, yes, after you turn on Allow access to file URLs on Paletmin's details page at chrome://extensions.

Does Paletmin remember my choice?

Each tab keeps its mode until you close it or quit the browser. An extension update may also return open tabs to Auto. Chrome also keeps temporary palette-detection and initialization state. Neither version stores page content, URLs, or browsing history.

Does Paletmin collect anything?

No. There is no account, no analytics, no server, and no network request of any kind. The Chrome privacy policy lists what the Chrome extension processes and stores. The Firefox add-on also declares in its manifest that it collects no data, and its repository carries a separate Firefox privacy policy.

Where is the source?

The Chrome repository and the Firefox repository hold the complete source under the MIT License, so you can read exactly what Paletmin does in a page. Bug reports and contributions are welcome in either.

How do I remove Paletmin?

In Chrome, open chrome://extensions and choose Remove on Paletmin's card. In Firefox, open about:addons and choose Remove from the extension's menu. The browser deletes the extension and the little it stored. Reload open pages afterwards to clear its changes.
