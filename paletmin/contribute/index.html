Paletmin is made by Ilia Ross and published under the MIT License. Contributions are welcome.

Ways to contribute

  • Report a bug or suggest an improvement. Tell us what happened and what you expected. Leave out private page content.
  • Report a website that does not switch, with its address and what you see, so its case can be looked at.
  • Contribute code or review a change. Keep changes focused, and run the tests in the repository before opening a pull request.
  • Share Paletmin with someone who could use it.

Thank you for using Paletmin and helping make it better.
