Help Paletmin grow

Paletmin is made by Ilia Ross and published under the MIT License, with a repository for Chrome and one for Firefox. Contributions are welcome in either.

Ways to contribute

  • Report a bug or suggest an improvement in the issues for Chrome or Firefox. Tell us what happened and what you expected. Leave out private page content.
  • Report a website that does not switch, with its address, your browser, and what you see, so its case can be looked at.
  • Contribute code or review a change in either repository. Keep changes focused, and run the tests in the Chrome repository before opening a pull request there.
  • Share Paletmin with someone who could use it.

Thank you for using Paletmin and helping make it better.
