Help Agemin grow

Agemin is made by Ilia Ross. Contributions are welcome.

Ways to contribute

  • Report a bug or suggest an improvement. Tell us what happened, what you expected, and which kind of key was involved. Never attach private keys, passphrases, or the files you encrypted.
  • Improve a translation, or clarify confusing wording. Agemin ships in thirty-one languages, and every catalog can be better.
  • Contribute code or review a change. Follow the repository's contribution terms and keep changes focused. Changes to the age implementation must keep the tests passing, including the checks against the age tool.
  • Share Agemin with someone who exchanges files with SSH or age keys.

An Agemin Pro purchase on the App Store supports development.

Thank you for using Agemin and helping to improve it.
